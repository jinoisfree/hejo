# 사장 프로필과 채팅 말풍선 (현재 명세)

적용 제품 커밋 `f116bdcae507d6559cd43c5db7b32d3a51b21578`(문 `a6266cd` 포함). 변경 기록: [HEJO-OWNER-PROFILE](../../changes/HEJO-OWNER-PROFILE-20261125/spec.md). 계약 원본: `schemas/hejo-wire-v1.json`(`owner_profile`), `schemas/pictures.md`(`owner` 사진, `/v1/owner`).

## 사장 프로필
- 원본은 그 문의 공용 창고 하나다. 이름 `<HOME>/shared/hejo/owner.json`(`{"v":1,"name":…}`, 0600), 사진 `<HOME>/shared/hejo/pictures/owner.png`(폴더 0700, 파일 0600). 쓰기는 문만 한다. `shared/hejo`는 없을 때만 0700으로 만들고 이미 있으면 권한을 바꾸지 않는다.
- 이름은 앞뒤 공백을 뺀 1~20자이며 줄바꿈·제어 문자를 받지 않는다. 비우면 "설정 안 됨". 깨진 파일·심볼릭 링크는 "설정 안 됨"으로 읽는다.
- HTTP: `GET`/`PUT /v1/owner`(`{"name": string|null}`, 잘못되면 400 `invalid_name`), 사진 `/v1/pictures/owner/owner`. 인증은 문의 HTTP 출입증.
- wire: welcome과 모든 roster(명단 요청 응답, 직원 사진 알림, `ref:"owner"` 변경 알림)에 `owner: {name, avatar}`. 앱은 welcome에 없으면 "설정 안 됨", roster에 없으면 기존 값을 유지한다. 앱은 프로필을 메모리에만 둔다.

## 이름이 쓰이는 곳
| 자리 | 이름 있음 | 설정 안 됨 |
|---|---|---|
| 앱 내 글 머리줄·검색 화자·스레드 복사·작업 공간 보기 | 이름 | `사장` |
| 디스코드 거울 글 표기 | 이름 | `사장` |
| 직원 대화 맥락 줄(스레드·방 놓친 글), 버튼 결정 문구 | 이름 | `나` |
| Hermes 출처 `user_name` | 이름 | 넣지 않음 |

이름을 바꾸면 그 뒤에 보내는 글부터 적용된다. 이미 보낸 글은 고치지 않는다.

## 앱 화면
- 설정 창의 "내 프로필" 영역에서 사진 고르기·지우기와 이름 저장. 채팅의 내 사진·머리줄 우클릭 "내 프로필…"이 이 영역을 연다. 연결이 없으면 저장·사진 버튼을 쓸 수 없다.
- 모든 직원 글(첫 글, 답글, 이어 쓴 글, 스트리밍, 첨부·긴 글·표·코드)은 회색 반투명 말풍선(`replyBackground`, 없으면 글자색 7%) 안에 그린다. 내 글은 사용자 말풍선 색. 두 말풍선은 같은 모서리(12)·안쪽 여백(12×8)이다.
- 표와 코드는 말풍선 안쪽 폭 안에서 줄을 바꾼다(코드는 글자 단위). 가로 스크롤은 없다. 첨부·버튼·칩·답글 묶음·답하는 중 줄은 말풍선 밖 아래, "더 보기/접기"는 말풍선 안이다.
- 머리줄: 직원 글은 왼쪽 `[사진] 이름 시간`, 내 글은 오른쪽 `시간 이름 [사진]`(시간이 가장 바깥쪽). 바로 앞에 보이는 글이 같은 사람 글이면(사장은 스레드 첫 글 포함) 머리줄을 생략한다. 보내는 중이면 시간 자리에 "보내는 중".
