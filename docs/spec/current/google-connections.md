## 현재 계약

Google 개인 해제는 해당 직원 계정·이메일과 전용 자격을 제거하고 명시적 미연결을 보존한다. 다음 연결은 새 계정 선택과 사용자 동의를 거친다. 다른 직원·공용·회사 계정은 변경하거나 revoke하지 않는다. 다른 서비스의 해제 계약은 유지한다.

연결 원본은 기존 `owner/vault.yaml`의 `google_connections`다. 직원 항목 부재만 legacy 경로를 허용하며 null·손상·전환 중·binding 불일치는 공용 자격으로 fallback하지 않는다. 직원 홈 `hejo/google-token.json`은 전용 자격 봉투이며 config는 조립 결과다. 메일·캘린더·Workspace 공식 도구와 worker·승인·undo는 같은 직원 binding을 검사한다.

인증 작업은 직원·기기·작업·세대에 묶이며 취소·만료·늦은 응답을 성공으로 표시하지 않는다. 실제 인증 시트의 창 닫기는 소유 인증 작업 취소를 요청한다. 이는 다른 일반 연결 작업의 닫기 계약을 바꾸지 않는다.

설치·복구는 단일 호환 검사기와 지원 선언을 사용한다. 전환된 연결을 이해하지 못하는 구버전 복귀와 자격 자동 복원을 거절한다. 전체 bundle은 키트와 지정 동반 파일·선택 스킬을 함께 적용한다. 명시적 LegacyUpgrade에서만 고정 생산자의 만료된 완료 disconnect를 현재 off·after 지문·CAS 등 설계10 조건으로 읽기 전용 인정한다. 일반 first/recovery의 거절은 유지한다.

## 검증과 한계

격리 통합·실제 AppKit 및 교차 모델 독립 검토를 수용했다. 운영 전환/설치/서명/서비스 재개 증거와 최종63조건 성공을 확인했다. GD-T19 네 항목은 사용자의 직접 확인이며 에이전트 독립 실계정 관측이 아니다. 과거 실패와 수정 이력은 구현 보고에 보존한다. 후속 유지보수는 실행 시점의 런타임 환경을 확인하며 계정 상태를 배포 전으로 되돌리지 않는다.
