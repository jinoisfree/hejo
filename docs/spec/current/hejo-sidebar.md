# HEJO 목록 선택 표시의 현재 계약

근간은 [ARCHITECTURE](../../ARCHITECTURE.md)의 관제 화면이다. 적용 제품 커밋은 `2240e44881274077bca3a2ffe636a597fb1a4a42`. 가짜 자료의 실제 AppKit 창에서 검증한 소스 기준이며 운영 설치·원격 반영을 뜻하지 않는다.

- **REQ-HSS-01 / AC-01:** 68pt 축소, 212pt 확장, 180~300pt 너비 조절 후 화면 안에 완전히 보이는 선택 행의 배경 네 모서리가 온전히 보인다. 오래된 셀 크기로 잘리거나 이웃 행을 침범하지 않는다. 전환 중 반전·동작 줄이기도 같은 최종 결과를 낸다.
- **REQ-HSS-02 / AC-01:** 선택 배경은 얼굴·방 사진·이름·핀·음소거·배지 뒤에 합성한다. 불투명 아이콘 내부 색을 파랗게 덮지 않는다. 밝음/어두움, 홈·일반방·DM, 단일·복수 얼굴에 적용한다.
- **REQ-HSS-03 / AC-01:** 선택 opacity spring, 섹션 여닫기, 검색, 스크롤 복귀, 선택·우클릭·끌기·접근성을 보존한다. 선택 상태·방 자료·읽음·배치 저장·통신 계약을 바꾸지 않으며 목록 전체 reloadData를 추가하지 않는다.

변경 근거와 검증 범위는 [판정서](../../changes/HEJO-SIDEBAR-SELECTION-20261123/verdict.md), 수락 절차는 [HSS 시험](../../../tests/acceptance/HEJO-SIDEBAR-SELECTION.md)을 참조한다. 작업별 Target 문서는 변경 기록으로 보존한다.
