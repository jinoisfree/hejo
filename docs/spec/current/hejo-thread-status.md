# HEJO 스레드 상태 막대의 현재 계약

근간은 [ARCHITECTURE](../../ARCHITECTURE.md)의 관제 화면이다. 적용 제품 커밋은 공개 이력 `872ab0e1c0da7d2377d868f40e2ce2562387998f`(개발 이력 원본 `f1cb67d3dfbd74f7479566db5b6cb5c6da53b065`, 제품 patch-id 동일). 가짜 자료의 실제 앱 모델·AppKit 카드 조립에서 검증한 소스 기준이며 운영 설치·원격 반영을 뜻하지 않는다.

상태는 기록장 투영을 읽는 `ThreadAssessment.assess` 한 곳에서 파생하고, 카드 상태 막대·종·알림 목록이 같은 결과를 쓴다. 새 저장 필드는 없다.

- **REQ-TD-01 / AC-01~05:** 직원 요청(버튼·reply_state=asked·승인 요청 문장)에 사장이 답한 뒤(승인 단어 여부 무관, 해당 요청 대상 또는 대상 없음) 작성이 끝난 직원 글이 있으면 완결이다: 초록 `#2EB67D`, 종 없음, 알림·질문 목록 제외. 작성 중(streaming)·생각 중 글은 근거가 아니다. 완결 뒤 새 요청은 그 요청 기준으로 다시 판정하고, 대상 지정 답이 남긴 요청은 대기(빨강)다. closed 초록, answered 처리 중 노랑, 승인 단어 직후 초록, 버튼 노출 규칙은 유지한다.
- **REQ-TD-02 / AC-06~07:** 요청이 있던 스레드는 보고 제목 표시(🔴 등) 색으로 되돌아가지 않는다. 판정 색이 없으면 작업 중 노랑, 아니면 색 없음이다. 요청 없는 보고만 제목 첫 표시로 색을 정하고(🔴❌🚨⛔ 빨강 `#E01E5A`, 🟡🟠⚠ 노랑 `#ECB22E`, 🟢✅☑✔ 초록 `#2EB67D`, 🔵ℹ📌 파랑 `#1D9BD1`), 작업 중이면 노랑이 우선한다.

이 계약은 HEJO-FOUNDATION spec REQ-HF-27.AC-03 상태 막대 줄의 완결·제목 색 규칙을 대체한다(사장이 고른 ddots와의 차이, 2026-11-24). 근거와 검증 범위는 [판정서](../../changes/HEJO-THREAD-DONE-20261124/verdict.md)를 참조한다.

## 가운데 창 알림 확인과 카드 제목 (HEJO-ALERT-SEEN)

적용 제품 커밋은 공개 이력 `b1fc6c49c33eee7ff1b5778adf13b67da992c08a`. 가짜 기록장·대역 문과 실제 앱 하네스(기록 나눠 받기 모드)로 검증한 소스 기준이며 서버 문 설치·앱 배포를 뜻하지 않는다. 근거와 검증 범위는 [판정서](../../changes/HEJO-ALERT-SEEN-20261125/verdict.md) 3차.

- **REQ-AS-01:** 사장이 직접 고른 스레드(가운데 창 카드 클릭·Enter·화살표, 채팅 스레드 클릭, "답글" 버튼, 말풍선·섬, 검색 결과, 스레드 링크, "의견" 버튼)가 알림(답이 필요 없는 직원 소식)으로 울리면 확인 처리되어 가운데 창에서 빠진다. 앱이 방에 들어갈 때 자동으로 잡은 답글 대상은 확인하지 않는다. 답 요청(질문) 카드는 선택으로 빠지지 않고 답해야 빠진다. 울리는 알림을 직접 고르면 읽음 요청은 `notice` 한 건이며 이것이 `thread:`·`bell:`을 함께 쓴다. 울리지 않는 스레드는 지금처럼 `thread` 읽음 한 건이다. 실패하면 아무 키도 바뀌지 않고 카드가 남으며, 다시 고르면 다시 요청한다. 기록 조정자는 선택·입력이 바뀌어도 지금 의도 세대의 읽음 요청은 남기고 옛 세대 요청만 버린다(새 세션이면 전부 버림). 창을 숨길 때만 의도 세대를 올린다.
- **REQ-AS-02:** 알림·답 요청 카드 제목(문 notice `preview`)은 글의 첫 비어 있지 않은 줄이다. 그 줄이 멘션만으로 이뤄져 있으면 다음 비어 있지 않은 줄을 " · "로 이어 붙이고, 길이는 300 글자 묶음에서 자른다. 스레드 요약의 `title`·`preview`·`rootPreview`와 섬 질문 미리보기(24)는 바뀌지 않는다.

이 절은 [HEJO-TODO-DRAWER](../../changes/HEJO-TODO-DRAWER-20261120/spec.md) AT-TD-39·[HEJO-UI-CLEAN](../../changes/HEJO-UI-CLEAN-20261123/spec.md) REQ-UC-03 AC-07의 "알림 카드는 열면 사라짐"을 출시 경로에서 성립하게 하고 그 범위를 사장 직접 선택으로 정한다.
