# 연결 재시작 화면

적용 기준: 공개 통합 커밋 `e8e28a998b8bbfc8b7586e328eebc9d7746fa9d2`의 전체 검증 및 로컬 앱 설치 완료. 개발 검증 커밋은 `fd49c1de12d3328a956df118bac8ffd3e6e7a6fe`이며 공개 이력과 분리 보존한다. 원격 푸시는 승인 대기다.
작업 원본: [연결 멈춤 수정](../../changes/f1c5ef47-8a5d-4479-871d-c48580bfdfdb/spec.md), [검증 판정](../../changes/f1c5ef47-8a5d-4479-871d-c48580bfdfdb/verdict.md).

- 재시작 단계는 ‘다시 시작’을 표시하며 저장 안내를 숨긴다. 일반 입력의 저장 문구·검증은 유지한다.
- 앱 내부 확인 sheet는 연결 창의 선호 높이와 키 대상을 유지한다. 시스템 인증 중 높이 전환은 기존 계약을 유지한다. 취소·닫기로 확인 대기를 끝낼 수 있다.
- 직접 재시작과 연결 단계 재개 모두 수락 후 응답 유실 시 재전송하지 않고 기존 job_status로 조회한다. 알려진 job을 우선하고 없으면 latest를 조회한다. 최근 기록은 현재 요청의 성공으로 단정하지 않는다.
- 현재 요청의 확정 완료는 이전 입력·추적 상태를 종료한다. 응답 유실 뒤 최근 결과와 불명확한 결과는 읽기 전용 재확인을 제공한다. 닫기는 서버 작업 취소가 아니다.
- 실제 운영 게이트웨이 재시작·메시지 전송은 이 검증에 포함하지 않는다.
