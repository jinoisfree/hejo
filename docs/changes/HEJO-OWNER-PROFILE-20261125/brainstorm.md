# HEJO-OWNER-PROFILE 브레인스토밍 결정 요약 (2026-11-25)

## 목적
사장이 자기 이름과 사진을 정하고, 그 이름이 앱 채팅·텔레그램·디스코드·직원 대화 맥락에 쓰이게 한다. 채팅의 말풍선 모양을 하나로 통일한다.

## 하는 것 / 하지 않는 것
- 하는 것
  - 설정에서 "내 프로필"(사진 고르기·지우기, 이름). 이름을 비우면 "사장".
  - 채팅 A안: 내 글은 오른쪽 파란 말풍선, 머리줄 `시간 이름 [사진]`(시간이 가장 바깥쪽), 이어 쓴 글은 머리줄 생략.
  - 에이전트 글은 길이·형식과 관계없이 모두 회색 반투명 말풍선(지금 짧은 답에 쓰는 색). 표·코드도 말풍선 안에서 폭에 맞춰 접는다(가로 스크롤 없음).
  - 내 말풍선과 에이전트 말풍선은 같은 모양, 색과 좌우만 다름. 머리줄은 에이전트 `[사진] 이름 시간`과 좌우 대칭.
  - 텔레그램·디스코드의 "사장" 표기와 직원 대화 맥락의 "나"를 설정한 이름으로.
- 하지 않는 것: 직원에게 "표를 좁게 써라" 같은 작성 규칙, 말풍선 색 설정 화면, 허브 계정 이름 변경, 서버 설치(별도 작업).

## 칸·원본·쓰기 주체·수명
- 이름·사진은 서버 공용 창고(`<HOME>/shared/hejo/`). 사진은 방 사진과 같은 `pictures/` 폴더. 새 칸 없음.
- 쓰기 주체는 문 하나(앱 요청), 바뀌면 연결된 모든 기기에 알림. 수명 영구(갱신·제거가 건드리지 않음).

## 실측 (공개판 `github/main` `c22e677` 기준)
- 앱은 내 글 화자를 "나"로 넘기지만 이름·사진을 그리지 않는다(`app/Sources/ConversationView.swift:1285`). 시간은 말풍선 아래.
- 에이전트 말풍선은 답글 중 짧고 단순한 글에만(`ChatStyle.swift:158` `isConversational`, `ConversationView.swift:1286`).
- 텔레그램·디스코드는 "사장" 고정(`gate/telegram.py:431`, `gate/discord.py:507`), 직원 대화 맥락은 "나"(`gate/context.py:25`).
- 사진 API `/v1/pictures/{employee|room}/{id}`(`schemas/pictures.md`)와 roster 알림이 이미 있다.
- Hermes는 `build_source(user_name=…)`를 직원 프롬프트의 `**User:**` 줄로 넣는다(본체 읽기만, `gateway/session.py:430`).

## 선행 조사
외부 조사 생략: 기존 직원 사진·방 사진·펫 이름 설정 방식을 그대로 재사용한다.

## 대안과 선택
- 채팅 배치: A안(오른쪽 말풍선 유지 + 머리줄) 채택. B안(슬랙식 왼쪽 정렬)은 내 글이 덜 띄고 말풍선 구조를 크게 바꿔 기각.
- 넓은 표·코드: 말풍선 안 폭 맞춤 채택. 가로 스크롤, 표·코드만 밖으로 빼기는 기각.
- 저장 위치: 문(공용 창고) 채택. 허브 회원 설정은 앱만 볼 수 있어 텔레그램·직원에 못 써서 기각.

## 가정
- 사용자 결정: A안, 에이전트 글 전부 말풍선, 표·코드 말풍선 안 폭 맞춤, 말풍선 모양 통일, 시간 가장 바깥쪽, 이름을 앱·텔레그램·직원 모두에 사용, 공용 창고 저장.
- 에이전트 제안: 사진 형식·크기는 직원 사진과 같음(PNG 변환, 512 KiB), 이름 1~20자, 디스코드도 텔레그램과 같이 바꿈.
