아예 숨기지 않고 자리만 남겨서, 일이 오면 같은 자리에서 늘어남.

좋은 점

  • 칸이 필요 없음 — ddots 두 칸(탭 + 채팅) 그대로, 채팅이 가장 넓음.
  • 알림 + 바로 답을 한곳에서(B). 펼치지 않고 버튼 하나로 끝.
  • 살아 있는 상태(D): 직원이 일하는 중인지 한눈에. 아이폰 사용자에게 익숙함.
  • 모든 상태가 같은 자리에서 커지고 작아짐 — 눈이 한곳만 보면 됨.

조심할 점

  • 창이 닫혀 있으면 안 보임 → 펫 배지(숫자)는 계속 필요.
  • 가운데 위는 왼쪽 방 탭과 멀어서 "누구 일인지"는 얼굴로 보여 줘야 함(B·C).
  • 움직임이 잦으면 방정맞음 → 늘어나는 건 새 답 요청·마감 임박일 때만, 몇 초 뒤 다시 작아짐.
  • 목록 전체 관리(정렬·미루기)는 알약으로 부족 → "전체 펼치기"로 할 일 칸(v14)을 여는 길을 남김.

제안

  • 평소엔 아일랜드만, 필요할 때 할 일 칸을 펼치는 조합. 접힌 막대(1~140번) 고민이 사라짐.
