왜 더 쉬운가

  • 한 문장 모델: 직원 고르기 → 일 고르기(또는 새 일) → 말하기. 메신저를 쓸 줄 알면 설명 없이 됨.
  • '스레드' 대신 '일': 사장이 생각하는 단위 그대로. 버튼도 "새 일 맡기기", 입력 줄도 "이 일에 이어서 말하기".
  • 모드 전환 없음: 답글/새 대화 토글을 없앰. 일을 골라 두면 이어서, 새 일은 파란 큰 버튼 하나. 입력 줄 위에 누구에게·어디에 보내는지 항상 글로 표시.
  • 필터 대신 저절로 나뉘는 3묶음: 내 답을 기다려요 → 하는 중 → 지난 일(접힘). 배울 것 없이 위에서부터 보면 됨.
  • 상태는 문이 이미 아는 것으로 자동 판단: 직원이 버튼·질문을 남김 = 기다림, 작성 중 = 하는 중, 그 밖 = 지난 일(다시 말을 걸면 위로 올라옴). 따로 '완료' 누를 필요 없음(문 변경 없음).
  • 나를 기다리는 일: 모든 직원의 기다리는 일을 맨 위 한 곳에. 펫의 빨간 숫자도 이 수 하나만 — 누르면 바로 그 일로.
  • 질문은 그 자리에서: "2시 / 4시" 같은 선택은 목록 카드에서 바로 누름.
  • 빨강 = 나를 기다림, 하나의 뜻만. 새 글은 굵은 글씨로만.
  • 숨은 기능은 표준 위치: 복사·링크·분기는 글 오른쪽 클릭, 단축키는 메뉴와 도움말에(화면에 안 박음).
  • 쉬운 말: "중지"→"멈추기", "직무 없음"→"아직 맡은 일 없음", 상태도 "쓰는 중·답을 기다려요·쉬는 중".

답글/새 대화 토글→ 큰 "새 일" 버튼 + 입력 줄 위 안내 문장
