칸마다 다듬은 것

  1. 머리 줄 = 공항 상태: 연결 점을 브랜드 밑으로 모아 따로 띠를 두지 않음(끊기면 이 자리와 입력 줄에만 표시).
  2. 직원 칸: 타일 숫자 점 하나만(새 글 수, 답 필요면 빨강). 한 줄 상태("답이 필요해요"), ⌘1~9로 바로 이동, ⌘K 전체 찾기(직원·스레드·글).
  3. 스레드 칸 거르기: 위 알약 대신 전체 / 답 필요 / 진행 / 완료 한 줄 전환. 답 필요 수만 빨갛게.
  4. 찾기: 지금 직원의 스레드 안에서 ⌘F.
  5. 스레드 카드: 신호는 왼쪽 색 막대 + 짧은 글자 하나. 안 읽음은 제목 앞 파란 점. 📌 고정(예약 보고 등)은 맨 위, 나머지는 최근 활동 순·날짜 묶음. 질문 카드는 선택 버튼을 카드에서 바로 누름.
  6. 대화 머리: 링크·분기·완료로 표시를 스레드 단위로 위에 한 번만(카드마다 줄 반복 없앰).
  7. 글 도구: 복사·링크·분기는 글에 마우스를 올릴 때만.
  8. 작성 중: ••• 옆 ■ 중지(⌘.). 지난 답글은 "이전 답글 N개"로 접힘.
  9. 새 글 알림: 위를 읽는 중 새 글이 오면 화면을 끌어내리지 않고 ↓ 새 글 1 단추.
  10. 입력 줄: 스레드를 고르면 자동으로 답글, ⌘N은 새 대화. 스레드마다 임시 저장. 첨부는 ＋·끌어 놓기·붙여 넣기. 첨부는 눌러서 미리보기(스페이스).
