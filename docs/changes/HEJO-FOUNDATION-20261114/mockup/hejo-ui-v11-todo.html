처리할 일이 쌓이는 세 갈래

답 요청직원이 질문·선택 버튼을 남김. 목록에서 바로 답1단계(문이 이미 앎)
D-day마감이 있는 일. D-7부터 쌓이고 가까울수록 빨갛게, 지나면 "마감 지남"1단계: 사장이 글에 오른쪽 클릭 → "할 일로(마감일)"
2단계: 직원이 찾은 마감이 저절로
할 일"나중에" 버튼, 직원이 제안한 다음 할 일1단계: 나중에·오른쪽 클릭
2단계: 직원 제안

쓰는 법

  • 위에서부터 처리: 마감 지남 → 오늘 → 답 요청 → 다가오는 일(7일 안). 순서는 저절로.
  • 목록에서 끝내기: 답·맡기기·내가 함·미루기. 처리하면 빠지고 "처리한 일"로.
  • 누르면 출처로: 오른쪽에 그 대화가 열리고 근거 글이 노랗게 — "이게 어디서 나온 일이지?"가 바로 보임.
  • 왼쪽 탭 = 거르기: "전체"는 모든 직원, 직원을 누르면 그 직원 것만. 빨간 숫자 = 처리할 일 수(펫 숫자와 같음).
  • 좁은 창: 이 칸은 "처리할 일" 탭으로 접힘(ddots 탭 줄 맨 위).

필요한 것

  • 1단계: 답 요청은 문 정보 그대로, D-day·할 일은 사장이 표시(처음엔 이 맥에 저장).
  • 2단계: 직원이 "할 일(마감일)"을 글에 붙여 보내는 약속(문 + 가이드북), 공항에 저장해 맥북 두 대가 같은 목록.
