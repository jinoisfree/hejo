규칙

  • 높이 고정(30px), 너비만 바뀜. 가장 넓을 때도 제목줄 안에서 끝남(브랜드·접기 버튼을 가리지 않음).
  • 늘어나는 때: 새 답 요청(B) · 직원 일 끝남(D2) · 마감 1시간 전(F). 그 밖엔 A 또는 D.
  • B·D2는 3~5초 뒤 A로 돌아감. 놓쳐도 빨간 점과 숫자가 남음.
  • 클릭: 알약 = 왼쪽 할 일 칸 열기/닫기, 알약 안 꼬리표·버튼 = 그 일로 바로.
  • 창이 닫혀 있으면 펫 배지가 같은 숫자를 보여 줌.
