접힌 할 일 — 25~32번 (꾸밈 대신 '무엇을 알려 줄까'를 바꿈)

같은 상황(할 일 5개, 급한 것 2개). 막대 모양이 아니라 알려 주는 내용을 바꿨다: 누가 · 어떤 종류 · 언제 · 얼마나 해냈나. 오른쪽 아래는 2배 확대. 이름은 예시.
