적용한 HIG 원칙

  • 계층: 사이드바(반투명 재질) → 목록 → 내용. 내용이 주인공, 장식은 최소.
  • 소스 목록 사이드바: 구역 머리글, 둥근 선택, 개수는 회색 캡슐(빨간 배지는 앱 아이콘·펫에만).
  • 툴바: 제목 + 부제(직원·상태), 동작은 아이콘 버튼(새 스레드·사이드바·접기)과 도움말.
  • 시스템 색·글꼴: 라벨 1·2·3차 색, 강조색 = 사용자 강조 색, SF Pro 13pt 본문·11pt 보조.
  • 라이트·다크 자동: 같은 의미 색으로 두 모드 지원.
  • 익숙한 패턴: Mail식 목록(파란 점 = 안 읽음), Messages식 말풍선·작성 중 말풍선·＋ 첨부.
  • 표준 컨트롤: 기본 버튼 하나만 강조색, 나머지 일반 푸시 버튼. 첨부는 Quick Look 타일.
  • 8pt 간격 격자와 넉넉한 클릭 영역(28pt 아이콘 버튼).
  • 접근성: 상태를 색만으로 표시하지 않음(점 + 글자), 대비 4.5:1 이상, 키보드 이동, 동작 줄이기 존중.
  • 적응형: 좁아지면 사이드바부터 숨김(분할 보기 규칙).
