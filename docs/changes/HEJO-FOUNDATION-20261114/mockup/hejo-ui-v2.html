펫 위 빨간 숫자
비서 · 중요 메일 3건이에요
(선택) 펫 말풍선 한 줄 미리보기

조작 요약

열기·닫기: 펫 클릭 / Esc / ⌄(펫으로 접기). 다른 앱 입력을 뺏지 않음.

직원 바꾸기: 왼쪽 탭. 빨간 숫자 = 안 읽은 글. 흐린 탭 = 직무 없는 직원.

스레드: 카드를 누르면 그 카드만 펼침(다른 카드는 접힘). 펼친 카드가 있으면 입력 줄은 그 스레드 답장, 없으면 새 스레드.

크기: 패널 가장자리를 끌어 키움. 탭 줄을 오른쪽으로 끌면 목록, 왼쪽 끝까지 끌면 숨김.

새 스레드: ✎ 또는 카드가 모두 접힌 상태에서 바로 입력.
