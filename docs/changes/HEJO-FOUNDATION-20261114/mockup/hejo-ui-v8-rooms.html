고질 문제: 단체방에서 누구에게 보내나

ddots는 얼굴을 누르면 글에 @이름이 끼워졌다. 그래서 — 깜빡하면 아무도 안 받거나 전원이 답함 · 글을 고치다 @가 지워짐 · 지금 누구에게 가는지 한눈에 안 보임.

해결: 받는 사람은 "글"이 아니라 "칸"

  1. 입력 줄 위 받는 사람 칸이 늘 보인다(메일의 받는 사람처럼). 보내기 버튼에도 "비서에게 ↑"라고 쓴다 — 누르기 직전에 한 번 더 확인.
  2. 얼굴 줄 = 받는 사람 고르기: 누르면 켜짐(파란 테 + ✓), 다시 누르면 꺼짐. 여러 명 가능. ddots와 같은 손동작, 글은 건드리지 않음.
  3. 똑똑한 기본값(그리고 늘 보여 줌)
    일 안에서 이어서 말하기그 일의 담당자가 미리 선택
    단체방에서 새 일안내원이 정하기가 기본(보낸 뒤 "→ 리서처가 맡았어요"), 얼굴을 누르면 직접 지정
    직원 1:1 방그 직원으로 고정(같은 입력 줄, 바꿀 수 없음)
  4. @이름 입력도 가능: 쓰면 칸이 같이 바뀜(키보드 사용자용). 글 속 @와 칸이 늘 같은 상태.
  5. 받는 사람 없음 = 못 보냄: 안내원도 끄고 아무도 안 고르면 보내기 버튼이 "누구에게 보낼까요?"로 바뀌고 잠김.
  6. 보낸 뒤 확인: 내 글 아래 "→ 비서, 리서처에게". 카드에는 담당·함께 표시.
  7. 담당 바꾸기는 따로: 카드 오른쪽 클릭 → "다른 직원에게 넘기기"(실수로 바뀌지 않게).
