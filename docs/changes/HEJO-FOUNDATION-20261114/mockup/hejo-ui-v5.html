ddots에서 가져온 모양

  • 어두운 바탕, 둥근 큰 창(펫 아래로 펼침), 맨 위 브랜드 + 버전(hejo.)과 종·사이드바·찾기·접기 아이콘.
  • 직원 = 둥근 사각 글자 타일, 오른쪽 위 색 숫자 점(빨강 답 안 함·주황 질문·하늘 새 글).
  • 구역⋮ 머리글과 구분선(직원⋮, 2단계 단체방⋮).
  • 목록 위 알약 신호(답 안 한 글·질문·알림), 카드 왼쪽 색 레일(보라 진행·주황 질문·초록 완료).
  • 대화: 파란 블록 말풍선 안 파일 줄, 이전 답글 N개 알약, ✅ 답변 완료 줄, ••• 작성 중과 ■ 중지, 링크·복사·분기 줄.
  • 입력: 답글 / 새 대화 전환, ＋ 원형, 둥근 칸, 원형 보내기.
  • 4판 HIG에서 유지: 세 칸 계층, 좁으면 접힘, 상태는 색 + 글자, 키보드·동작 줄이기.
