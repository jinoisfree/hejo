카드는 어디서 오나 (사장이 적지 않아도 채워짐)

지금 답해 주세요직원이 질문·버튼을 남긴 글(기존 정보) — 카드에서 바로 답1단계
오늘 마감직원이 "할 일"로 남긴 것(예: 메일에서 찾은 마감). 직원 글의 할 일 표시가 필요2단계(문 + 가이드북)
오늘 예정예약 작업(아침 보고·정기 정리) 시간표2단계(문에 예약 목록)
내가 미뤄 둔 것"나중에" 버튼·카드 오른쪽 클릭 → "오늘 할 일에"1단계(앱 저장) → 2단계(공항 저장, 두 기기 공유)

쓰기 편하게

  • 아침 첫 화면: 하루 처음 펫을 열면 "오늘"이 먼저 열림. 펫 빨간 숫자 = 지금 답할 것 + 오늘 마감.
  • 카드에서 끝내기: 답·맡기기·미루기(내일로)·체크. 대화를 열 필요가 있을 때만 "대화 열기".
  • 저절로 사라짐: 답하면 "끝낸 것"으로 내려가고, 자정에 비워짐(미룬 것만 다음 날로).
  • 위에서부터 급한 순: 답할 것 → 마감 → 예정 → 끝낸 것. 진행 막대로 오늘 얼마나 했는지.
  • 직원 탭은 그대로: 대화는 지금처럼 직원 탭에서. "오늘"은 모아 보는 입구일 뿐.

솔직한 평가

  • ✅ 1단계만으로도 쓸모: "지금 답해 주세요"(여러 직원의 질문을 한 번에 처리) + 미뤄 둔 것.
  • ⚠️ 진짜 힘은 2단계: 마감·예정이 저절로 들어와야 "오늘 할 일"다워짐. 그 전엔 기다림 탭과 거의 같음.
  • ⚠️ 직접 입력하는 할 일 앱으로 만들지 않기: 적는 수고가 생기면 안 씀. 직원이 채우고 사장은 처리만.
