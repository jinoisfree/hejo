막대 규칙

  • 폭 20px, 글자 없음. 위에 표시 하나: 할 일 0이면 초록 ✓, 있으면 빨간 숫자.
  • 가운데 짧은 세로 손잡이 — 끌어서 펼치거나 눌러서 펼침.
  • 새 일이 오면 저절로 펼침(직접 접은 동안엔 숫자만 올라감).
  • 배경은 거의 안 보이는 결 — 방 탭 줄과 붙어 하나처럼 보임.

규칙

  • 왼쪽에서 오른쪽으로만 바뀜
    • 할 일 카드 → 옆 방 선택 → 그 옆 채팅(그 대화로 내려가 펼침·반짝)
    • 방 누름 → 옆 채팅만
    • 할 일 칸은 방을 바꿔도 그대로(모든 방)
  • 급한 것이 맨 위: D-DAY·지난 마감·답 요청은 '급한 것' 묶음에 붉은 테두리.
  • 위에서 거른다: 전체 / 답 요청 / 마감 / 할 일.
  • 처리하면 카드만 사라지고 대화는 방에 남음.

보완 적용

  • 빈 상태 = 20px 막대(글자 없이 ✓ 하나): 칸이 통째로 사라지지 않아 방·채팅이 거의 안 움직임. 새 일이 오면 저절로 펼침(아래 A~C).
  • 할 일 수를 세 곳에: 칸 머리 숫자, 창 머리글 "처리할 일 5 · 급한 것 2", 펫 배지 (⑤). 창이 닫혀 있어도 펫에서 보임.
  • 직접 접기(⟨ 접기): 대화에 집중할 때. 접어도 막대에 숫자가 남음.
  • ddots 부분은 그대로: 방 탭 줄·채팅 카드·입력 줄(설명 줄 없음).
