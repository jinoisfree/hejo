- 조사 방법
  - 대상: ddots `Sources` 제품 파일 전부(`*Smoke.swift` 제외)와 hejo 고정 사본(커밋 e77a5f7).
  - 갈래: 대화 화면, 동작 규칙, 카드·글, 펫·앱·설정, 부가 기능, 애니메이션 전수.

  - 사장이 직접 고른 것만 hejo 값을 유지한다(§0-2 목록).

- 표기
  - ddots 파일은 `D:파일:줄`, hejo 파일은 `H:파일:줄`(e77a5f7 기준, 줄은 함수 이름과 함께 찾는다)로 적는다.
  - 처리: **ddots** = ddots대로 고침, **유지** = 사장 선택이라 그대로, **제외** = 이유와 함께 가져오지 않음.
