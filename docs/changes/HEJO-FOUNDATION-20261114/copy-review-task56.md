# TASK-56 계약·문구 대조

보완 71을 기존 책임 자리에서 처리했다. 동기화 실패는 기존 실패 알림, 업데이트는 기존 버전 동의 창, 다운로드는 기존 파일 저장 실패 안내를 사용한다. 비밀번호 저장 실패에만 "비밀번호를 저장하지 못했어요. 다시 로그인할 때 입력해 주세요."와 확인 단추를 추가한다. 실패 대화상자는 로그인 창이 연결 뒤 닫혀도 사라지지 않도록 저장 시 바로 표시한다.

구획 이름·사진·정의는 기존 layout:sections 배열, 접힘은 구획별 키다. 읽기에서 옛 open 값을 받아들이고, 새 정의 쓰기에서는 그 칸을 제외한다. 옛 앱은 새 접힘 키를 모르므로 최신 앱끼리 접힘을 맞춘다. 구획 정의의 배열 원본은 유지한다. 다만 open 없는 새 정의는 옛 앱의 필수 open 디코더와 호환되지 않으므로 두 Mac 앱을 함께 갱신해야 한다. 새 디코더는 open이 있는 옛 정의와 없는 새 정의를 모두 읽는다.

출입증은 기존 형식 제한을 지킨다. 비밀번호 항목만 기호를 허용하고, 기존 서비스·계정 이름으로 Keychain 자료를 읽는다. 실제 비밀번호 항목을 사용하는 시험은 하지 않으며 주입한 저장 동작으로 바이트 왕복과 실패 알림을 확인한다. 기존 문 연결 통합 시험은 임시 자격 계정의 가짜 출입증만 Keychain에서 왕복·제거한다.
