## 요구·수락 기준
REQ-HSS-01: 확장·축소·너비 조절 후 선택 배경 전체가 해당 행 안에 표시된다.
- AC-01(정상·경계): 좁은 68pt에서 넓은 212pt로 전환하고 넓은 최소 180pt·최대 300pt로 조절하면, 화면 안에 완전히 보이는 선택 행의 둥근 사각형 네 모서리가 모두 보인다. 상·하 또는 좌·우가 오래된 크기로 잘리거나 이웃 행에 침범하지 않는다. 전환 중 재전환 및 동작 줄이기에서도 끝 결과가 같다.
REQ-HSS-02: 선택 배경은 방 내용 뒤에 있다.
- AC-01(정상): 선택 전후 불투명한 시험 아이콘의 내부 색이 파랗게 덮이지 않고 이름·핀·음소거·숫자 배지를 읽을 수 있다. 밝은/어두운 화면, 홈·일반방·DM, 단일/복수 얼굴 및 방 사진에 적용한다.
REQ-HSS-03: 기존 목록 동작을 보존한다.
- AC-01(회귀): 선택 전환의 기존 spring 소멸/등장, 섹션 여닫기, 검색, 스크롤 후 셀 재표시, 선택·우클릭·끌기·접근성이 유지된다. 목록 전체 reloadData를 추가하지 않는다.

위험도: 일반(UI 버그 수정). 필요 증거: 1(빌드), 2(가짜 자료 회귀 시험), 3(실제 AppKit 창 렌더링). 운영 연결이나 실제 메시지 없이 임시 홈·가짜 명부로 확인한다.
범위 밖: 통신·저장 규격, 운영 설치·게이트웨이, 전체 앱 투명도, 색 테마 재설계, 다른 앱 변경.
