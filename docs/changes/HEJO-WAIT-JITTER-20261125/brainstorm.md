# HEJO-WAIT-JITTER 브레인스토밍 결정 요약 (2026-11-25)

## 목적
답을 기다리는 동안(직원이 답하는 중) 대화 화면과 왼쪽 목록이 위아래로 튀지 않게 한다.

## 하는 것 / 하지 않는 것
- 하는 것: 가운데 대화 목록과 왼쪽 목록의 흔들림. 스크롤을 옮기는 모든 지점에 "누가·왜 옮겼는지" 계측을 넣어 재현하고, 원인을 확정한 뒤 원래 책임 자리에서 고친다. 같은 상황의 회귀 시험을 추가한다.
- 하지 않는 것: 기다리는 동안 CPU 사용량(관측 약 24%) 개선, 스크롤 구조 전면 재설계, 게이트 변경.

## 칸·원본·쓰기 주체·수명
- 칸: 앱 대화 화면(쓰기 주체·수명 점검표는 design 2.1절). 원본 `app/Sources/NativeThreadList.swift`(읽기 위치·따라가기 책임), 갱신 호출자 `app/Sources/ConversationView.swift`(왼쪽 목록 포함). 새 칸 없음.
- 쓰기 주체: 스크롤 위치는 `NativeThreadList` 하나만 옮긴다(현행 원칙 유지).
