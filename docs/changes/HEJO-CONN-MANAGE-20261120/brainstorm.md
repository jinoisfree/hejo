# HEJO-CONN-MANAGE 브레인스토밍 결정 요약

2026-11-20 · 진행 방식: 연합개발(계획 검증 켜기)

## 요청
"연결할 수만 있지 연결 해제가 안 되고, 중간에 옵션을 바꾸고 싶은데(시놀로지 폴더 설정 등) 그 기능이 없다. 모든 앱이 다 다르기 때문에 맞춤 설정은 어려울 것 같고 방법 없냐."
추가(같은 대화): "맥북에서 실행 중 암호나 지문 입력 시 이 창(에이전트 연결)이 꺼진다."

## 목적
모든 연결에서 **연결 / 설정 바꾸기 / 해제**를 같은 자리에서 한다. 앱별 맞춤 화면 없이.

## 하는 것 · 하지 않는 것
- 하는 것: Mac 앱 줄과 계정·서비스 줄(시놀로지, Notion, Google 개인/회사, X, Instagram)에 세 동작. 설정 바꾸기는 처음 연결 때의 단계 안내를 현재 값이 채워진 채로 다시 띄워 바꿀 단계만 고친다. 해제해도 넣어 둔 값(비밀번호·토큰 포함)은 모두 남긴다. 시놀로지 중복 두 줄을 한 줄로. 지문·암호 확인 뒤 연결 창이 사라지는 문제 수정.
- 하지 않는 것: 앱별 맞춤 설정 화면. 대화 채널(Slack, hejo, iMessage) 해제(지금처럼 다시 시작만). 해제 때 값 지우기.

## 사장 결정 (2026-11-20, 질문 도구 답)

| 방법 | 공통 3동작 + 설정 다시 하기(추천안) |

## 대안과 선택
- 채택: 공통 3동작 + 설정 다시 하기(Home Assistant 통합의 "구성/삭제"와 같은 방식, 지식 기반·웹 재조사 안 함).
- 기각: 숨은 해제만 꺼내기(폴더 하나 바꾸려고 처음부터 다시), 앱별 맞춤 화면(앱마다 화면 추가).

## 위험도 1차 판단
고위험: 권한 범위(Google 개인·회사 담당)와 자격 값 흐름, 운영 시설(team-kit) 변경, 앱 공개.
