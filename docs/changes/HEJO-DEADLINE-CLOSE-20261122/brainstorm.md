## 사장 결정

1. 묵은 항목은 **우클릭 메뉴로 사장이 닫는다**(기능 추가).
2. 카드를 누르면 **hejo 알림 글로 이동**한다. 이동할 글이 없으면 **없음을 표시**한다.
3. 닫는 주체: **문이 바로 닫는다**(team-kit 새 닫기 명령을 문이 부름).
4. 메뉴: **완료로 닫기 · 취소로 닫기** 두 가지.
5. 확인: **확인 창 없이 + 되돌리기**.

## 에이전트 제안 (계획에서 확정, 사장 결정 아님)

- 근거 문장은 "hejo에서 사장이 완료로 닫음 / 취소로 닫음"으로 자동 기록한다.
- 1:1 방으로 대신 이동하는 동작은 없앤다(교체).
- 문은 기존 행동 기록(`shared/hejo/actions.jsonl`)에 남긴다.
- 되돌리기는 **보내기 전 대기 시간**으로 구현하고 team-kit의 다시 열기는 쓰지 않는다. 다시 열기로는 이미 닫힘으로 다시 칠한 hejo 알림 글의 버튼이 돌아오지 않기 때문이다(`repaint_closed_hejo`가 `buttons=[]`로 편집). 대기 시간은 [제안] 5초다.
