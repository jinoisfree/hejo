## 작업 기준에 대한 주의

이 저장소의 로컬 `main`은 설치 앱과 다른 개발 이력이며 HEJO-PERF의 통지 묶음(`receive`의 `performUpdates`)이 들어 있지 않다. 이 작업은 로컬 `main`이 아니라 기준 커밋(원격 공개 main)에서 갈라낸 별도 작업 공간·브랜치에서 한다. 로컬 `main`과 다른 작업 공간의 파일은 건드리지 않는다. 작업 문서는 계획 담당 폴더의 것이 원본이다.
