# HEJO-DRAWER-INLINE 브레인스토밍 결정 요약

## 목적
처리할 일 칸이 대화 창 밖 왼쪽에 검은 불투명 판으로 따로 붙어 있어 이질적이다(사장 스크린샷, 0.2.5). 칸을 대화 창 안 **방 목록과 채팅 사이**로 옮기고, 색을 방 목록과 같은 결로 맞춘다.

## 하는 것 / 하지 않는 것
- 한다: 칸 위치 바꾸기(방 목록 | 할 일 | 채팅 | 웹 칸), 열 때 창이 오른쪽으로 넓어지기, 배경과 카드 색 맞추기, 옛 배치(창 밖·덮기) 경로 제거.
- 하지 않는다: 칸 내용·카드 종류·마감 요청·알약 동작 변경, 칸 너비(290) 변경, 앱 공개·버전 올림.

## 칸·원본·쓰기 주체·수명
관제 화면(hejo 앱, `app/`) 칸 안의 화면 배치만 바뀐다. 새 칸·새 저장 값 없음. 열림 여부는 기존 `hejo-local.json` `todoDrawerOpen` 그대로.

| 카드 색 | 부드럽게 맞춤(선택 = 방 목록 선택 행 채움, 급함 = 배지 글자만 빨강) | 그대로 |
