## 최초 조사 시점의 문제와 근거

- 사용자: 앱이 사용 불가능할 정도로 느리다.
- [확인] 09:40~09:41 KST 실행 프로세스 CPU 100.0%, 이후 99.1%. 3초 sample의 메인 스레드 234개 중 228개가 GateClient.receive → ConversationController.receive 경로였다. 이는 표본 수이며 CPU 시간의 정밀 계측값은 아니다.
- [확인] 화면 갱신, notices, assessment, timeline, 날짜 해석이 해당 호출 트리에 반복된다. 원시 표본은 개인정보가 섞일 수 있어 저장소에 넣지 않는다. 로컬 증거 위치는 인계 대화에 둔다.
- [확인] Controller.receive는 model.apply의 onChange를 받은 뒤 마지막에 다시 notifyChange한다. `ConversationModel.bell`은 `notices`를 호출하고, `ConversationView.threadContent`가 카드별로 bell을 요청한다. sidebar도 방마다 notices를 두 번 요청한다. timeline은 전체 messages를 필터하고 정렬한다.
- [확인] 설치 앱은 0.2.7(9), BuildInfo tree `f9e2fb8710934d39cf3b724aa84a912800b804a7`, dirty=true. 당시 HEAD와 동일 빌드라는 보장은 없었다. 이후 검토 후보의 설치·실행 대응은 구현 보고의 TASK-04 기록을 따른다.
- [미확정] 수신 프레임의 종류·빈도, 최초 악화 시점, 위 경로 외 추가 병목. 표본으로 무한 루프나 서버 이상을 단정하지 않는다.
- 외부 조사 생략: 저장소 내부 버그이며 실제 프로세스·호출자·소비자 근거가 있다.

## 범위와 요구

REQ-HP-01: 같은 프레임 처리 중 중간 상태의 중복 화면 갱신을 제거한다. 동기 호출이 반환될 때 최종 상태를 전달하는 기존 계약은 유지한다.

REQ-HP-02: 같은 화면 갱신에서 동일 상태의 알림·스레드·타임라인을 반복 도출하지 않는다. 렌더 파생값은 영구 저장하거나 다른 공항에 공유하지 않는다.

REQ-HP-03: 글·순서·읽음·종·질문·24시간 알림 경계·홈 범위·초안·스트리밍·재연결 결과를 보존하고 실제 응답성 개선을 확인한다.

범위 밖: 게이트·허브·인증·저장 형식·스레드 병렬화·전역 비동기 debounce·운영 설정 변경·대화 삭제·캐시 초기화·서버 재시작·실제 메시지 전송. 새 SwiftUI 화면 없음.

## 수락 기준

| AC | Given / When / Then | 시험 |
|---|---|---|
| HP-01 | 상태를 바꾸는 프레임을 한 번 receive하면 반환 전에 최종 화면 통지가 한 번 전달된다. 기존 명시적 중첩 transaction 및 transaction 밖 동기 통지도 유지한다. 오류·전용 응답 경로는 의미를 보존한다. | AT-HP-01 |
| HP-02 | 동일 렌더 상태에서 여러 카드·사이드바·종이 같은 방을 조회하면 방 알림 전체 도출은 한 번 이하이며 결과가 기준 구현과 같다. 렌더 종료·상태 변경 뒤 오래된 결과를 재사용하지 않는다. | AT-HP-02 |
| HP-03 | 메시지 추가·편집·삭제, 읽음/종/확인 변경, 명부·방·홈 변경, 재연결, 24시간 경계 및 실패 입력에서 기준의 관측 결과가 같다. | AT-HP-03 |
| HP-04 | 동일 가짜 대규모 기록장을 쓰는 기준/수정 빌드 비교에서 수신→화면 반영 비용이 줄고, 연속 수신 중 입력·방 전환이 처리된다. 실제 설치 앱에서도 기존 포화 경로 감소와 사용자 동작 응답을 확인한다. 가짜 부하 통과만으로 실제 문제 해결을 선언하지 않는다. | AT-HP-04 |

TASK-01A 검토 결과와 원시 계측 근거는 [verdict](verdict.md)에 있다. v3의 수치 합격선 원본은 [AT-HP-04](../../../tests/acceptance/HEJO-PERF.md#at-hp-04-성능-및-실제-앱)다. 비교 입력·빌드 옵션·계측 방식·기대값은 동결한다. 구현자는 합격선을 완화하지 않는다. 실제 앱에서 체감 문제가 남으면 HP-04 미충족으로 재조사한다.
