## 목적
처리할 일 칸·채팅 머리·방 목록에서 같은 정보를 여러 번 보여 주는 것을 없애고, 더 직관적이고 깔끔하게 만든다.

## 하는 것 / 하지 않는 것
- 한다: 채팅 머리를 "제목 알약" 하나로, 처리할 일 칸 머리 한 줄·카드 목록 새 모양, 칸 선택 ↔ 채팅 글 연결, 중복 표시 제거, 질문 단추 글자, 밝은 테마 버그·작은 다듬기.
- 하지 않는다: 답글/새 글 토글과 직원 얼굴(캐릭터) 줄 변경(사장: 그대로), 칸 너비·배치(HEJO-DRAWER-INLINE 결정), 통신·저장 형식, 공개.

## 칸
관제 화면(hejo 앱, `app/`) 안 화면 표현만. 새 저장 값·새 원본 없음.

## 사장 결정 (시간순 마지막이 이김)
| 항목 | 결정 |
|---|---|
| 방향 | "더 직관적·깔끔, 중복 제거" 깔끔안 → 깔끔안 2(줄 목록·직원 사진) |
| 직원 사진 | 할 일 줄에 실제 직원 사진(에이전트 사진) |
| 알약 | 채팅방 제목을 감싸는 알약. 할 일이 생기면 `제목 │ ●` 빨간 점, 매우 부드럽게 깜빡임. 활동은 오른쪽으로 늘어나며 표시 |
| 제목 설명 글 | "조직원들의 소식과 대화" 없어도 됨 |
| 답글/새 글·캐릭터 줄 | 그대로 둔다 |
| 할 일 카드 | 테두리 있는 카드(final-3) |
| 빨간 세로줄 | 할 일 카드와 채팅 카드가 같은 위치(테두리에서 안쪽 6pt, 위아래 10pt)로 통일(final-4) |

## 에이전트 제안(사장이 시안으로 확인)
- 칸 머리 한 줄(필터 토글 + ✕), 칸 제목·묶음 제목 없음, 급한 것/나머지 사이 가는 선.
- 카드: 사진 · 제목 · 상태 한마디 · 오른쪽 시각. 0개 필터 흐리게.
- 칸이 열려 있으면 채팅 위 질문/알림 칩 줄 숨김(같은 목록).
- 고른 카드와 채팅의 그 글이 같은 파랑으로 이어짐, 입력은 자동 답글.
- 알약 우선순위: 문제 > 새 질문 미리보기 > 일하는 중 > 점. 제목 부분 클릭 = 칸 여닫기, 늘어난 부분 클릭 = 그 행동.
- 보이지 않는 개선: 칸 열 바닥까지 같은 톤, 밝은 테마 방 목록 묶음 글자 버그, 좁은 방 목록 툴팁, 직원 얼굴 툴팁, 카드 올림 표시, ↑↓ Enter, 입력 줄 분홍 표식 조사, 접기 단추 주인 조사.
