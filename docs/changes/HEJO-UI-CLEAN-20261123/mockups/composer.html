입력 영역 단순화 시안 — 홈(hejo) 방처럼 받을 직원이 여럿인 방 기준. 1:1 방은 받는 사람 표시가 없고(지금도 얼굴 줄 없음), 후보가 한 명뿐이면 숨김.

① 평소 (새 글)

토글·얼굴 다섯 개 → 작은 "받는 사람" 하나. 글에 @이름을 쓰면 자동으로 바뀜
