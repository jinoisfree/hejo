· 상자 카드 → 한 줄 목록: 테두리·바탕 없는 줄(48pt). 한 화면에 6~7개. 올리면 옅은 바탕, 고른 줄은 옅은 파랑
· 이름 글자 → 얼굴: 줄 맨 앞에 직원 얼굴. 누구 일인지 글을 안 읽고도 보임(아래 줄에서 이름 빠짐)
· 시각은 오른쪽 끝에 따로(3분 · 방금 · 10/19). 아래 줄은 상태 한마디만: "답을 기다려요" / "마감 34일 지남" / "마감 7일 남음" / "알림"
· 급한 것과 나머지 사이 가는 선 하나(제목 글자 없이). 급한 줄은 왼쪽 빨간 세로줄 + 빨간 상태 글자
· 고른 줄 ↔ 채팅 글이 같은 파랑으로 이어짐: 줄을 누르면 그 글에 파란 테두리, 입력 칸은 자동으로 "답글" + 그 직원
· 문제 없을 때 알약 숨김: 연결이 정상이고 일하는 직원이 없으면 채팅 머리는 방 이름만. 끊기면 그때 주황 알약
