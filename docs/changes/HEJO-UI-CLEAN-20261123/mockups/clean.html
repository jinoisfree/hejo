없앤 중복
· 할 일 창 머리 두 줄 → 한 줄: 필터 토글 + 닫기 ✕ ("처리할 일" 제목 없음 — '전체 5 · 답 요청 · 마감 · 알림'이 곧 제목)
· "급한 것 / 나머지" 묶음 제목 없음 — 급한 것은 늘 위, 빨간 세로줄로 구분
· 채팅 위 "질문 2 / 알림 3" 칩 줄 — 할 일 창이 열려 있으면 숨김(같은 목록). 닫혀 있을 때만 보이고, 누르면 할 일 창이 그 필터로 열림
· 닫는 방법 하나: ✕ (알약의 "닫기 ‹" 글자 없음, Esc는 유지) · 개수는 필터 한 곳에만(홈 아이콘은 점 하나)
· 방 이름 아래 설명 글 "조직원들의 소식과 대화" 없음 · 질문 단추는 글자만(승인·거절·의견·확인)
