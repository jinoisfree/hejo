# ADR-0001 직원은 성격과 출입증만 가진다

- 상태: 승인(2026-11-27, 사용자 "구현진행해"로 개정안 2판 승인)
- 근거 문서: [HEJO-EQUIP design.md 2판](../changes/HEJO-EQUIP-20261126/design.md)
- 대체: 같은 작업의 개정안 1판(가이드북 → 상자 → 기본 도구 3층)은 채택하지 않음

## 결정
1. 직원은 성격과 출입증(들어갈 수 있는 도구 창고 칸 목록)만 가진다. 직책·직무는 저장하지 않는다.
2. 가이드북은 스킬이다. 직원은 일이 생기면 가이드북을 펼치고, 도구 목록에서 필요한 도구를 찾아 출입증이 있는 칸에서 그때 꺼내 쓴다(Hermes Tool Search: `tool_search` → `tool_describe` → `tool_call`).
3. 도구 창고 칸(`pack.yaml`)이 도구 목록과 필요한 Hermes 기본 도구(`core_toolsets`)의 원본이다. 도구 목록표(`catalog.json`)와 직원 설정의 도구 범위는 조립 결과다.
4. 코드는 "이 칸 출입증이 있나"만 묻는다. 기존 직책 질문은 단계적으로 옮긴다(이행 중 직책 키 = 같은 이름의 칸 키).
5. 도구 검색 켜기와 멘션 없는 새 글의 기본 담당은 사장 지시서에 둔다.

## 이유
- 사용자 구상: "직원이 가이드북을 찾아보고 도구 창고의 도구 목록에서 필요한 도구를 찾아 가져와 조합한다."
- Hermes에 스킬과 Tool Search가 이미 있어 새로 만들 것이 적다.
- 출입증이 없으면 고객 응대 직원이 메일 발송·터미널 같은 칸을 열 수 있어, 출입증 하나만 직원별로 둔다.

## 결과
