# HEJO-BUBBLE-WIDTH 수락 시험

- 2판(spec 2판과 짝, 계획 검증 1회차 BW-R1~R3 반영) · 상태: 명세 확정 / 코드 작성(`app/Tests/BubbleWidthTests.swift`, 기대값 소유는 기획설계) / 실행: 기준본 재현 22·보존 12 일치, 수정본 34개 통과(검증 담당 직접 실행) / 독립 검토: 계획 검증 2회차 APPROVED(2판)
- 가짜 문장만 쓴다. 증거 수준: 공통 5절 2(앱 시험 하네스). 실제 설치 앱 확인은 릴리스 작업.
- 관측: `NativeThreadCard.layout`이 돌려주는 글 배치(`bubble`·`text` 틀과 높이). 카드 여백 18(`OwnerProfileTests`의 배치 도우미와 같음), 사진 34, 간격 9, 글씨 14 기준. 허용 오차는 폭 ±1pt(화소 올림).
- 독립 계산: `C = W − 36 − 43`, `B = min(C, max(240, 0.75 × C))`. 가장 긴 줄 폭은 그 줄만 같은 글꼴로 따로 잰다(배치 코드의 결과를 가져오지 않는다).
- **기준본 실행:** 시험을 제품 코드 수정 전에 먼저 써서 착수 커밋에서 돌리고 아래 "기준본 기대"와 맞는지 로그로 남긴다. 보존이 실패하거나 재현이 통과하면 제품을 고치지 말고 멈추고 보고한다.
