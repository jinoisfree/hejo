# HEJO-SLACK-MOVE 수락 시험 명세

3판 · 2026-11-21(계획 검증 1·2회차 반영) · 명세 [spec.md](../../docs/changes/HEJO-SLACK-MOVE-20261121/spec.md), 설계 [design.md](../../docs/changes/HEJO-SLACK-MOVE-20261121/design.md).

상태: 명세 완료 · 코드 미작성 · 미실행 · 독립 검토 대기(계획 검증). 기대값의 출처는 spec 요구와 design 표다. 구현 담당은 이 명세를 시험 코드로 옮기되 기대값과 합격 기준을 바꾸지 않는다. 바꿔야 하면 멈추고 보고한다.

공통 조건: 임시 `HERMES_HOME`, 가짜 명부(가짜 직원 A·B·C), 가짜 금고 값, 가짜 외부 응답만 쓴다. 실제 Slack·인스타·네이버 호출과 운영 홈 접근이 없어야 한다. 소켓 경로가 길어지지 않게 `HEJO_GATE_TEST_TMPDIR`를 쓴다. 문 시험은 이 저장소 `tests/acceptance/test_slack_move_gate.py`(새 파일), team-kit·직원 플러그인 시험은 `HD` worktree의 기존 시험 폴더에 둔다.
