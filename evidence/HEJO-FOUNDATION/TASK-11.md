# TASK-11 아일랜드 증거와 수동 확인 자리

자동 시험은 가짜 명부·주입 시계·임시 홈·루프백 문 대역을 사용한다. 아래 캡처는 AppKit의 cacheDisplay로 만든 자동 자료이며 실제 운영 연결이나 수동 조작 완료 증거가 아니다.

- [평소 사장 차례와 일하는 직원](task11-working-automatic.png): 두 칸과 구분선, HEJO. 로고, 높이 30.
- [연결 끊김](task11-disconnected-automatic.png): 주황 테두리·재접속 안내, 별도 끊김 띠 없음.

AT-HF-53~56 자동 검사는 칸·너비·높이·시계 기반 유지 시간·우선순위·실패/업로드·클릭 대상·끌기 제외·동작 줄이기를 단언한다. 실제 HTTP 업로드와 WebSocket 전송 확인·재접속 뒤 수동 재전송은 통신 대역 시험으로 검증한다. 실행 명령과 결과는 impl-report TASK-11의 로그를 따른다.

AT-HF-56 수동 항목은 TASK-09에서 확인한다. 아래 항목은 아직 미실행이다.

- [ ] 서로 다른 방의 답 요청 3개에서 사장 차례 칸 클릭 → 가장 오래된 질문의 카드 펼침·1.5초 강조·스크롤 위치.
- [ ] 일하는 직원 칸 클릭 → 해당 직원 탭, 호버 → 최근 질문 한 줄·열기 표시·답 버튼 없음.
- [ ] 연결 끊김과 재연결 → 주황 알약·초 표시·지금 연결·2초 복구 안내.
- [ ] 보내기 실패 → 초안 첫 말 유지·다시 보내기·성공 뒤 사라짐. 파일 세 개 중 두 개 완료 → 2/3.
- [ ] 좁은 창·사이드바 변경 중에도 높이 고정·직원 칸부터 압축·제목과 겹침 없음.
- [ ] 알약 위 드래그 → 창 이동 없음; 알약 밖 머리글 → 기존 창 이동 유지.
- [ ] 일반 모드에서 직원 칸 글자에 밝은 띠가 왼쪽에서 오른쪽으로 1.6초마다 지나감. macOS 동작 줄이기에서는 밝은 띠가 멈추고 흐린 글자만 남으며 너비는 즉시 전환.

이번 작업은 9판 제목줄 변경만 적용한다. 이전 TASK-06의 끊김 띠·별도 알림 줄 관련 수동 비교는 이 증거 자리의 아일랜드 기준으로 확인하고, 나머지 대화·펫 동작은 기존 체크리스트를 유지한다. 촬영 시 개인 자료는 포함하지 않는다.
