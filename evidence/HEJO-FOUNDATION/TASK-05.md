# TASK-05 수동 증거 자리

상태: 수동 미실행. 자동 시험 결과는 impl-report TASK-05와 로컬 로그를 따른다. 아래 자료가 없다는 사실을 통과로 취급하지 않는다.

- [ ] 다른 앱의 문서에 입력하는 동안 펫 클릭 → 대화 자리 열림, 입력 포커스 유지.
- [ ] 다시 클릭·Esc·펫으로 접기·메뉴 열기를 순서대로 실행해 상태 확인.
- [ ] 일반 동작에서 0.30초 genie가 펫 발치로 펼쳐지고 접히는 화면 녹화.
- [ ] macOS 동작 줄이기 켬 → 같은 조작에 변형 없이 즉시 전환.
- [ ] 실제 다중 화면 가장자리 이동·화면 연결 해제 후 배치 확인.

스크린샷 자리: `task05-open.png`, `task05-folded.png`, `task05-reduced-motion.png`.
녹화 자리: `task05-focus-and-genie.mov`. 현재 파일은 아직 없다. 촬영할 때 다른 앱의 개인 자료는 포함하지 않는다.

자동 AppKit `cacheDisplay`로 촬영한 [펫과 빈 대화 자리](task05-automatic-open.png)는 별도로 동봉했다. 임시 설정·대역 상태만 사용했으며, 다른 앱의 실제 입력 포커스나 화면 녹화를 증명하는 자료는 아니다.
