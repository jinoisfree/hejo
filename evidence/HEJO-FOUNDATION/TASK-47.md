제목·소개·세 수·색·세션 줄·고정/거르기·안내·하단 동작을 비교한다. 710×610에서 검색 구획 y=209, 행 시작 y=243, 행 높이 66·행 간격 8이다. 서비스 선택은 AppKit 기본 NSSegmentedControl이므로 구획 내부 폭 분배가 원본 SwiftUI Picker와 다르며, 기본 단추의 바탕 농도·기준선과 접속 줄의 약 2pt 차이가 있다. 보완 60 뒤 접근 실패 줄은 원본 ‘기록 폴더에 접근할 수 없음’만 보이며 사용 가능 여부는 teal/gray 점으로만 구분한다. 아래 단추의 글꼴은 13pt·높이 24pt이고 원본과 분리 실측한 폭은 새로고침 69pt·동작 미리보기 96pt·승인 알림 연결 안내 125pt다. 본문·추론·사용량은 표시하거나 저장하지 않는다.

우선순위와 동작은 원본 CoreTests 분리 실행과 제품 시험에서 별도 검증한다. 원본 PetView는 승인 대기/오류 동작을 시선보다 우선한다. 화면 도구를 쓰는 작업은 가장 먼저 시작한 작업의 명확한 창을 바라본다. 승인 창 위치는 추정하지 않는다.

훅 시험은 임시 홈·가짜 설정만 사용한다. 실제 CLI 설정은 내용을 열지 않는 lstat 메타데이터 지문으로, 실제 다운로드 폴더는 항목 이름으로만 전후 대조한다. 실제 설정의 내용 해시를 검증했다고 주장하지 않는다.
