# TASK-12 대화 안 작성 중 표시 증거와 수동 확인 자리

아래 캡처는 자동 자료다. AppKit `cacheDisplay`로 만들었고, 가짜 명부·주입 시계·임시 홈을 썼다. `cacheDisplay`는 CALayer 반짝임 띠를 찍지 않으므로, 캡처에는 흐린 바탕 글자만 보인다. 반짝임 위치·깜빡임 켜짐/꺼짐은 AT-HF-57 자동 시험이 시계를 주입해 단언한다.

- [기다림](task12-waiting-automatic.png): 작성 중 줄은 "작성 중 12초"다. "● ● ●"은 없고, 높이는 22 그대로다.
- [흘러나옴](task12-streaming-automatic.png): 마지막 글자 오른쪽에 2pt 파란 커서가 있고, 작성 중 줄은 없다.

AT-HF-57 수동 항목은 TASK-09에서 확인한다(아직 미실행).

- [ ] 실제 직원 답을 기다릴 때 "작성 중" 글자에 밝은 띠가 1.6초마다 지나가고, 경과 초가 1초씩 오른다(60초 이상이면 "N분 M초").
- [ ] 글이 흘러나오는 동안 커서가 글 끝을 따라가며 0.5초 간격으로 깜빡이고, 줄바꿈·카드 높이가 흔들리지 않는다. final 뒤에는 커서가 사라진다.
- [ ] macOS 동작 줄이기: 반짝임이 멈추고 흐린 글자만 남는다. 커서는 켜진 채 멈춘다.
- [ ] 밝은 모드에서 반짝임 띠가 보인다(TASK-11 아일랜드와 같은 부품).
