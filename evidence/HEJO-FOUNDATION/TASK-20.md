# TASK-20 사진·색·사이드바 화면 증거

비교: 목록 머리의 크기·굵기·들여쓰기·간격, 사진 크기와 고정 행 강조 위치를 원본에 맞췄다. 직원 이름 색은 Q1·REQ-HF-23에 따라 명부 색으로 바꿨다. 사장 글·직원 글·접힌 답·아일랜드·작성기와 별도 말풍선에서 같은 초록 사진을 확인했다. 질문·알림 숫자는 별도 AppKit 그리기 시험에서 노랑·파랑 픽셀을 확인한다. 5개 1:1·3개 단체방·빈 고정 자리·이동·알림 끔 합계는 SidebarLayout 자동 입력 표로 확인한다.

한계: hejo는 독립 AppKit 시험 실행 파일에서 만든 창이다. ddots는 원문 함수와 가짜 모델을 조합한 참조 창이며, 원본 앱의 바깥 레일·모든 메뉴·대화 전체를 실행한 캡처가 아니다. reference_capture.py의 계정·통신·명부·사진 공급자는 대역이다. 원본 파일은 읽기만 했다. 실제 두 Mac, 실제 운영 문에 새 앱을 연결한 사진 변경·동기화·사용자 눈 확인은 TASK-23과 비설계자 검토에 남는다. 이 증거의 도달 수준은 2다.

재현과 전체 로그는 미추적 `.build/task20/reference_capture.py`·`capture_final.py`·`capture-final.log`·`reference-capture.log`에 있다. 캡처는 가짜 HTTP 서버와 앱의 실제 인증 사진 요청·메모리 썸네일을 사용한다.
